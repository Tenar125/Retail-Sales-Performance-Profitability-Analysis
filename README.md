Project Overview:

This project analyzes retail sales data to identify key performance metrics, trends, and profitability insights. It combines Python, SQL, and Power BI to clean data, run queries, and create visual dashboards for business decision-making.
Business Goal:

Understand which products, categories, and cities generate the most revenue.
Analyze customer buying behavior.
Identify seasonal trends and peak sales months.
Recommend strategies to improve profitability.

🗂 Project Structure:

📁 data/          → Raw and cleaned CSV datasets
📁 notebooks/     → Python notebooks for data cleaning & analysis
📁 sql/           → SQL scripts for querying the database
📁 dashboards/    → Power BI dashboards / exported images

Tools & Technologies:

Python (pandas, matplotlib, seaborn) – Data cleaning & visualization
SQL – Querying sales and customer data
Power BI – Interactive dashboards & reports
Excel / CSV – Raw dataset format

Key Analysis Performed:

Total sales and profit by category and product.

Revenue and order insights by city and customer type.

Average order values and comparisons.
